# Lorem Ipsum

- `li 3p` generates 3 paragraphs (five sentences each).
- `li 3s` generates 3 sentences.
- `li 20w` generates exactly 20 words.
- Spaces and full names also work: `li 3 paragraphs`, `li 2 sentences`.
- Return copies and pastes into the active app. Command-Return copies only.

Use any positive whole number. Large requests repeat the built-in text and
may take longer to generate and paste. Text is generated only on selection,
so typing a large number does not slow down the results list.

Runs locally with /usr/bin/python3; no downloads or dependencies.
