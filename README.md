# Alfred workflows

Inventory of the 28 workflow folders in this directory, inspected on 14 September 2026. Descriptions follow the saved `info.plist` configuration and bundled source; this is an inventory, not a claim that every workflow has been tested on every Mac.

Each `user.workflow.<UUID>` directory is one workflow. Its readable name, triggers, connections and often its scripts are stored in `info.plist`. Other files can include executable helpers, icons, data, documentation and `prefs.plist` settings.

Type keyword examples into Alfred. A **file action** or **Universal Action** is invoked on selected files/folders rather than by typing a keyword. Inspect Hotkey blocks in Alfred to see the shortcut assigned on your Mac.

## Using Notes on another Mac

The default folder is:

```text
~/Library/Mobile Documents/iCloud~md~obsidian/Documents/csaborio
```

The leading `~` follows the current Mac user; the final `csaborio` is the vault name. Change **Notes folder** in the Notes workflow configuration if necessary. Keep the vault downloaded in Finder so content search can read it promptly.

The workflow detects Python in `/opt/homebrew/bin/python3`, `/usr/local/bin/python3`, Alfred’s PATH, and a working developer-tools `/usr/bin/python3`. No additional Python packages are needed. Python installation instructions are available in [Alfred’s dependency guide](https://www.alfredapp.com/help/kb/install-dependencies/).

Use `md ` to list notes or `md meeting` to search. Filename/path matches take priority; content is searched only if there are no filename/path matches. Hidden folders are skipped. The old `work::meeting` syntax is not implemented.

## Moving this collection to another Mac

Syncing these folders carries the workflow definitions and bundled files. It does not install the external apps, command-line tools, or external scripts mentioned above.

The main machine-specific items visible in this collection are:

- **Favourite Folders:** absolute path to its `fav_folders.txt` configuration.
- **Convert PDF to Markdown:** absolute path to a separate MarkItDown virtual environment.
- **OCR → Markdown (Spanish)** and **Touch Files with [Date]:** helper scripts outside this directory.
- **Familia:** Python must be discoverable in Alfred’s environment; its vault must exist locally.
- **Lorem Ipsum** and **EmojicHunt:** explicitly use `/usr/bin/python3`; a Homebrew Python installation alone does not change that path.
- **OneDrive upload workflows:** require an `rclone` account configuration outside these folders.
- **App integrations:** require their respective installed apps and any macOS automation permissions used by the actions.

If a workflow shows no results, open its debugger in Alfred, run its trigger, and inspect the error output. Check that the edited workflow has synced, its paths exist, and its dependencies are available to Alfred.
